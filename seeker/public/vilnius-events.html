Public WordPress REST API

The site exposes event records as a custom event post type through its public REST API. The event collection is available at https://www.vilnius-events.lt/wp-json/wp/v2/event; there is no separate public API guide linked from the site.

REST API · WP/V2

Concert and festival queries

GET · JSON
01

List events

Fetch the custom event records in pages of up to 100. Use the response’s pagination headers and the page parameter to continue.

/wp-json/wp/v2/event?per_page=100&page=1
02

Filter by category

categories accepts a WordPress category ID. On this site, Concerts is 4 and Festivals is 81.

/wp-json/wp/v2/event?categories=4&per_page=100&page=1
/wp-json/wp/v2/event?categories=81&per_page=100&page=1
03

Homepage event JSON

A helper returns a small selection of highlighted event cards. It is useful for examples, but it is not the full event catalogue.

/helpers/json-events/
Event fields need parsing The REST records include title, link, categories, image and content.rendered. The date field is the WordPress post date. Event dates, venues and ticket links may appear on the event page, outside the API description. Seeker checks the page for these details; missing or ambiguous values can be edited.
