About MusicBrainz

Music metadata and the API endpoints Seeker can query.

♫

Community-maintained music metadata

MusicBrainz catalogs artists, releases, recordings and related entities. Its REST API is rooted at https://musicbrainz.org/ws/2/. Records have stable MBIDs (MusicBrainz IDs), which let clients link an artist to their releases and other data.

REST API · /WS/2

Three useful request patterns

GET · JSON
01

Search artists

Browse artists linked to Lithuania’s area, then retain records whose main associated country is LT. Browse supports offsets beyond the search endpoint’s 500-result cap.

/artist/?area=0785dc14-96af-3dc4-bde4-dcdfc2e2d0d6&fmt=json&limit=100&offset=0
02

Look up an artist

Use an MBID to request details, including genre data.

/artist/{MBID}?inc=genres&fmt=json
03

Browse release groups

Use an artist MBID to retrieve album, EP and single groups.

/release-group?artist={MBID}&limit=100&offset=0&fmt=json
Request limits Seeker requests up to 100 records at a time, at least 2 seconds apart. The LT country field indicates an artist’s main associated country; it does not establish nationality.
